# 设计规范 - DebatePrep

## 设计理念

| 属性 | 定义 |
|------|------|
| **核心风格** | 深色专业 (Dark Professional) |
| **设计语言** | 高端、克制、专注、智能 |
| **情感关键词** | 可信赖、高效、专业、沉浸 |
| **目标感受** | 让用户感觉像在使用一款专业的研究分析工具 |

## 6. 动效规范

### 6.1 过渡时间

| 类型 | 时长 | 缓动 | 用途 |
|------|------|------|------|
| 快速 | 150ms | ease-out | 按钮、链接悬停 |
| 标准 | 200ms | ease-in-out | 卡片、输入框状态 |
| 中等 | 300ms | ease-in-out | 展开/折叠、模态框 |
| 慢速 | 500ms | ease-in-out | 页面切换、加载 |

### 6.2 悬停效果

```css
/* 卡片悬停 */
.card {
  transition: border-color 200ms ease, box-shadow 200ms ease;
}
.card:hover {
  border-color: var(--primary);
  box-shadow: 0 0 0 1px var(--primary);
}

/* 按钮悬停 */
.button {
  transition: background-color 150ms ease, transform 150ms ease;
}
.button:hover {
  transform: translateY(-1px);
}

/* 禁止使用 scale 变换避免布局抖动 */
```
