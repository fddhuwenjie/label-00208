# 需求规格说明书

## 项目概述

| 属性 | 值 |
|------|-----|
| 项目名称 | DebatePrep - 辩论赛智能备赛助手 |
| 项目类型 | 本地文档智能分析工具 |
| 目标用户 | 辩论赛参赛者、教练、研究人员 |
| 交付形式 | Docker 容器化 Web 应用 |
| 访问方式 | `http://localhost:8501` |

## 业务目标

为辩论赛备赛提供高效的文档管理与智能搜索能力，帮助用户：
1. 快速从海量资料中定位关键论据
2. 通过语义联想发现相关概念和论点
3. 系统化管理和组织辩论素材
4. 构建正反方论点体系

### F2. 智能搜索与联想

#### F2.1 关键词精确搜索
| 需求ID | 描述 | 优先级 |
|--------|------|--------|
| F2.1.1 | 精确匹配关键词 | P0 |
| F2.1.2 | 高亮显示匹配内容 | P0 |
| F2.1.3 | 显示匹配片段上下文（前后各 2-3 句） | P0 |
| F2.1.4 | 显示来源文档和位置 | P0 |

#### F2.2 布尔搜索
| 需求ID | 描述 | 优先级 |
|--------|------|--------|
| F2.2.1 | 支持 AND 操作符（多词同时出现） | P0 |
| F2.2.2 | 支持 OR 操作符（任一词出现） | P0 |
| F2.2.3 | 支持 NOT 操作符（排除特定词） | P0 |
| F2.2.4 | 支持括号组合复杂查询 | P1 |

#### F2.3 模糊与同义词搜索
| 需求ID | 描述 | 优先级 |
|--------|------|--------|
| F2.3.1 | 模糊匹配（容错1-2字符） | P1 |
| F2.3.2 | 内置同义词词典 | P1 |
| F2.3.3 | 用户可自定义同义词规则 | P2 |

#### F2.4 语义联想搜索 ⭐核心功能
| 需求ID | 描述 | 优先级 |
|--------|------|--------|
| F2.4.1 | 基于词向量的语义相似度计算 | P0 |
| F2.4.2 | 自动扩展相关概念（如"年轻人"→收入、就业、消费、压力等） | P0 |
| F2.4.3 | 显示联想词及其相关性分数 | P0 |
| F2.4.4 | 基于上下文共现词分析 | P1 |
| F2.4.5 | 构建概念-子概念树状结构 | P1 |

**语义联想实现策略**:
```
输入关键词 → 
  1. 提取关键词周围上下文（前后2-3句）
  2. 使用 TF-IDF + Word2Vec 找出高频共现词
  3. 基于词性标注提取相关名词/动词短语
  4. 使用 Sentence-Transformers 计算语义相似度
  5. 输出排序后的相关概念列表
```

## 技术规格

### 技术栈
| 层级 | 技术选型 |
|------|----------|
| 语言 | Python 3.11+ |
| Web 框架 | Streamlit |
| 文档处理 | python-docx, openpyxl, pandas, pdfplumber |
| 中文分词 | jieba |
| 搜索引擎 | Whoosh |
| 语义分析 | sentence-transformers, gensim |
| 数据存储 | SQLite + 文件系统 |
| 容器化 | Docker + Docker Compose |

### 系统架构
```
┌─────────────────────────────────────────────────────────┐
│                    Streamlit Web UI                      │
├─────────────────────────────────────────────────────────┤
│                    业务逻辑层                            │
│  ┌─────────┬─────────┬─────────┬─────────┬─────────┐   │
│  │ 文档    │ 搜索    │ 语义    │ 内容    │ 辩论    │   │
│  │ 处理器  │ 引擎    │ 分析    │ 管理    │ 功能    │   │
│  └─────────┴─────────┴─────────┴─────────┴─────────┘   │

│                    数据存储层                            │
│  ┌─────────────────┬───────────────────────────────┐   │
│  │  SQLite 数据库   │   Whoosh 索引 + 向量存储      │   │
│  └─────────────────┴───────────────────────────────┘   │

```
